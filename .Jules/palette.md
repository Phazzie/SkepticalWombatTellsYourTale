## 2024-05-14 - Keyboard Accessibility and Context for Dynamic Lists
**Learning:** Repeating inline action buttons (like "Approve" or "Resolved" on list items) lose their context when read out by screen readers without surrounding visual cues, and custom interactive elements masquerading as buttons or accordions often lack native keyboard focus indicators.
**Action:** Always add dynamic, context-aware `aria-label`s (e.g., `aria-label={"Approve: ${concept.name}"}`) to repeating action buttons, and explicitly include clear `focus-visible` utility classes (e.g., `focus-visible:outline-none focus-visible:ring-2`) on custom interactive elements to ensure they are fully navigable via keyboard. Also ensure accordions use `aria-expanded` and `aria-controls` referencing unique IDs.
